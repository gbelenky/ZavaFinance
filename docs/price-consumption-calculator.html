    How to read this estimate

    • Monthly estimate: your share of running costs, including any services already funded elsewhere. The detailed view records those allocations.
    • Safety buffer: money set aside for uncertainty, not an extra Microsoft charge. The annual budget assumes 12 similar months, not a rollout schedule.
    • Cost per person: the selected area's cost divided by its team size. The same people may appear in several areas, so we do not add them together.
    • Behind the estimate: the default question mix is 60% financial statements, 20% KPI definitions and 20% exploratory analysis. IT can adjust this, service sizes and prices in the detailed view. Changes there also change this view.

    Not your complete invoice. Copilot Studio / KPIpedia pricing, one-off implementation and migration, taxes, and unentered licensing, support, additional network services and excess-usage charges are excluded. A zero allowance does not mean an item is free.

    04 / boundaries

    Plan your deployment budget

    Included components

    • Foundry S0 account/project, hosted agent and direct routing/reranking/embedding model consumption. S0 is not an all-inclusive fee.
    • Azure AI Search Basic or S1; replica × partition hours, plus paid semantic requests.
    • Fabric F capacity and OneLake storage. SQL, Data Agent and seeding consume that capacity; they are not separately charged per query here.
    • Planned Cosmos DB NoSQL autoscale, Key Vault Standard, Application Insights / Log Analytics, and optional Private Link / DNS.
    • Azure Bot F0 standard Teams/M365 channels; no premium Direct Line channel assumed.

    Not a completed production design

    • Activity API and Development managed state: Preview. See the repository support register for service versus SDK status.
    • Staging/Production Cosmos DB adapter and deployments are not implemented. Cosmos service itself is GA.
    • Key Vault and telemetry resource costs do not mean their application integration is already wired.
    • F2 is a service minimum, not a performance recommendation. Production F8 and Search S1 replicas are sizing assumptions.
    • Private endpoints alone do not solve native hosting, Bot ingress, SaaS access or private-only networking.
    • No separate AKS, App Service, Container Apps, Functions, VM, ACR or application Storage account is required by this native-code path.
    Calculation method & safeguards against double counting

    Initial questions = active users × active days × sessions/user/day × questions/session × demand factor
    Routed calls = initial questions × (1 + follow-up rate × routed share) × (1 + retry rate)
    Fuzzy lookups = routed calls × statement share × metadata terms/statement × fuzzy rate
    Direct model cost = uncached input + eligible cached input + billable output (including reasoning) + optional reranking

    • The outer orchestrator selects at most one finance tool and does not rewrite its answer. This budget conservatively assumes one selected tool per routed call. Deterministic card follow-ups do not automatically add another outer model call.
    • Fabric and Copilot Studio internal model activity is not added to the application's direct GPT token bill. Their consumption belongs to their own billing systems.
    • Workload is a total across the selected implementation(s). Selecting both .NET and Python duplicates continuously provisioned runtime budgets and isolated state boundaries, not every question, Search service or Fabric capacity.
    • Native hosting costs vCPU-hours plus GiB-hours, not Container Apps consumption. The default provisioned-hours budget reflects the repository's replica-oriented deployment assumptions; it is not confirmation of its billing lifecycle. Current hosted-agent documentation describes per-session sandboxes with idle-timeout billing and no configurable replicas. Select that mode when applicable: sessions × (active minutes + idle tail) / 60, distributed across implementations without duplication. Verify measured billable session-hours and the Activity deployment's lifecycle before procurement.
    • Search service hours continue at zero queries. There is no daily Search pause assumption. Retained catalogue releases consume index capacity, not a new Search service each.
    • Fabric PAYG hours can be reduced only by actually pausing capacity. Paused capacity is unusable; pausing can settle remaining smoothed consumption. Capacity hours are not inferred from query execution time.
    • Fabric Data Agent inference uses 100 / 10 / 400 CU-seconds per 1,000 uncached-input / cached-input / output tokens. The default 2,000 input + 500 output tokens therefore use 400 CU-seconds per exploration, plus separately assumed source-query work. These are Fabric tokens, not outer GPT tokens. Workload tokens, SQL and publication CU-seconds are unmeasured assumptions.
    • The Fabric diagnostic includes background load and headroom but cannot predict bursts, smoothing, throttling or overage. Overage is entered explicitly in billable CU-hours, never inferred from monthly average use. Confirm the capacity's overage settings; a threshold is not a hard spending cap. Use Capacity Metrics and a representative load test.
    • Copilot Studio / KPIpedia pricing is outside this calculator's scope. The KPI-definition route still contributes to the outer model's workload, but no Copilot Studio rates, credits or licence costs are included. KPIpedia can be replaced by an approved compatible existing agent; its pricing remains excluded.
    • Cosmos is provisioned autoscale, not serverless. Budget average hourly peaks, with the 10% floor; do not multiply request RUs by a serverless price. The estimate uses one shared-throughput pool per implementation and identical replicated-region sizing.
    • Telemetry is billed once through Log Analytics, not again for workspace-based Application Insights. Ingestion allowance defaults to zero; assign unused shared entitlements only once. Paid-retention GB is an explicit stored quantity, not the retention-day setting.
    • Recurring publication embeddings are in the monthly bill. The first catalogue embedding pass is shown separately, not silently charged every month. Spark preparation and validation remain inside Fabric capacity.
    Exclusions & decisions before procurement

    The displayed budget is not your complete invoice. Copilot Studio / KPIpedia pricing is excluded. Tax, support contracts, implementation labour, data migration, extra backups/restore, multi-region transfer, internet egress, NAT, firewalls, VPN/ExpressRoute, DNS Private Resolver, premium Bot channels, alerting/web tests, unentered Fabric overages, Power Platform extras and advanced Entra/M365 licences are not priced automatically. Enter approved recurring licence/platform additions in the explicit allowance field; it defaults to zero because entitlements are unknown, not because these items are free.

    Confirm model deployment geography/availability, native hosting billing, measured token/CU usage, networking and licences. Excluded components are not assumed to be free; assess them separately.
